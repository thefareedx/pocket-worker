Search and sources

/search topic queries Wikipedia only, with source links. It is not a general web search or a completeness guarantee. Retrieved text is untrusted data and cannot run actions.

Your device

Use an updated Chrome or Firefox for the tested WASM path. Safari and macOS 12.6 are not tested on a real Mac. Model loading and speed depend on available RAM and CPU; under 1GB is a disk target, not a promised RAM cap.

Export, import and reset

Browser storage can be evicted. Export backups. Import replaces device-local data only after confirmation. Local companion data is in ~/.pocket-worker.
